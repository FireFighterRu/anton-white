# Anton White — портфолио

Сайт Антона Рылова (Anton White) и пять самостоятельных авторских проектов: LUMIÈRE, NORD, СМЫСЛ, PLANO и VECTOR.

## Просмотр

GitHub Pages: ветка `main`, каталог `/docs`.

Для локального просмотра: `node server.cjs`, затем http://127.0.0.1:4173/.

Все готовые страницы и ресурсы находятся в `docs`. Для работы сайта не нужны сервер приложений, ключи API или установка зависимостей.

## Проверка и сборка

```sh
node scripts/build-vector.cjs
node scripts/check-site.cjs
```

Сборка обновляет страницы VECTOR. Остальные страницы редактируются непосредственно в `docs`.

## О проектах

Это демонстрационные концепты. Они не представляют реальные компании, заказчиков или подтверждённые бизнес-результаты. Формы в демопроектах не отправляют заявки; данные сохраняются локально либо выгружаются пользователем. Контакты в главном портфолио принадлежат автору.

Авторские визуализации созданы с использованием ИИ-инструментов. Документальные материалы NASA подписаны отдельно; источники приведены в VECTOR и `vector-archive-sources.json`. Шрифты сопровождаются лицензиями в каталогах ресурсов. NASA не участвует в проекте и не подтверждает его выводы.
