Лететь ради данных.

ДОСЬЕ ПРОГРАММЫ / СЦЕНАРИЙ

Наблюдать — значит оставаться полезным.

Горизонт рассматривается как носитель атмосферных приборов. Сценарий строится вокруг участка измерения: попасть в нужный район, обеспечить устойчивые условия для датчиков и сохранить запас на безопасное возвращение.

01

Выйти в район

Потратить часть энергии на переход и набор выбранного режима. Согласовать профиль с научной задачей и погодными условиями.

02

Измерять

Выполнять наблюдение с учётом качества данных. Контролировать питание, температуру и влияние самого аппарата на датчики.

03

Вернуться с данными

Завершить участок с достаточным запасом ресурсов. Сохранить измерения и сведения об условиях для последующей обработки.

У каждого решения есть цена.
