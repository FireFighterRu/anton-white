Стриж

Когда корпус тоже работает крылом.

Стриж — концепт для исследования интегральной компоновки. Плавный переход корпуса в крыло меняет не только силуэт: вместе с ним приходится заново искать баланс объёма, устойчивости и управления.

ДОСЬЕ ПРОГРАММЫ / СЦЕНАРИЙ

Один аппарат. Несколько проверяемых режимов.

Предполагаемая роль Стрижа — носитель исследовательского оборудования для изучения интегральной компоновки. Ценность миссии — сопоставимые наблюдения при последовательном изменении условий, а не достижение рекордной скорости.

01

Подготовить

Зафиксировать конфигурацию оборудования, положение центра масс и состав измерений. Изменение полезной нагрузки должно оставаться заметным в документации.

02

Наблюдать

Сопоставлять поведение на выбранных режимах с ожиданиями. Для каждого режима заранее определить признаки, требующие прекращения исследования.

03

Сопоставить

Связать полученные данные с версией геометрии и условиями. Решить, какую гипотезу проверять следующей.

У каждого решения есть цена.
